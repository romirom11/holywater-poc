# HOLYWATER PoC — Specification

Status: **approved** (2026-10-21)

## 1. Goal

A minimal autonomous agent: input — an idea (1–3 sentences of text), output — a single video file,
8–30 s, vertical (9:16), with sound, in which the spoken line is heard **verbatim** as written in the input text.

One command → one file:

```bash
uv run hw generate "Night, rain, a taxi driver looks in the mirror and says: \"Are you sure this is the address?\"" --out runs/
```

## 2. Hard requirements (from the task)

| # | Requirement | How it is verified |
|---|-------------|--------------------|
| R1 | Input: idea, 1–3 sentences | CLI argument / stdin |
| R2 | Output: video 8–30 s | `ffprobe` duration gate |
| R3 | 1–2 shots concatenated into a final file | assemble stage, ffmpeg concat |
| R4 | Sound is mandatory; the line is spoken **word for word** | STT verification (WER gate) + the line is taken from the input text, never from the LLM |
| R5 | One command / one call | `hw generate` |
| R6 | Autonomy: retries, fallbacks, state, logs | Prefect + quality gates + SQLite state |

## 3. Non-functional requirements (ours)

- **Clean, modular code**: layers `domain / providers / stages / flows / media / quality / observability / storage`; every provider behind a Protocol; swapping a model = a config change.
- **DRY**: one way to call fal (`providers/fal_base.py`), one way to call an LLM with structured output, one ffmpeg wrapper.
- **Configurable**: all models, generation parameters, quality thresholds and retry policies live in `config/pipeline.yaml`. Secrets only in `.env`.
- **Observable**: no error or warning is ever lost — everything goes to the per-run JSONL log and to the DB (`stages.error_json`).
- **Idempotent**: re-running with the same `run_id` skips stages whose artifacts are already valid (by `input_hash` in the DB).
- **Measurable**: every run ends with `report.json` containing technical metrics and a cost estimate.

## 4. PoC boundaries (what we deliberately do NOT do)

- No HITL pauses (the points are documented but disabled via config).
- No Postgres/S3 — local SQLite + media on disk.
- No Prefect Cloud / deployments — local ephemeral server.
- No complex editing (transitions, titles, music) — concat + loudness normalization.
- No cross-shot character consistency via reference images (documented as a next step).

## 5. Stack (approved)

| Layer | Choice | Why |
|-------|--------|-----|
| Language | Python 3.12, `uv` | fast, AI SDK ecosystem |
| Schemas / validation | pydantic v2, pydantic-settings | LLM structured output, config, artifacts |
| Orchestration | Prefect 3.x | retries, state, logs and UI out of the box; minimal boilerplate for a PoC |
| LLM | OpenRouter (OpenAI-compatible API, `response_format: json_schema`) | one entry point to any model, easy to swap in config |
| Video | fal.ai `bytedance/seedance-2.5/text-to-video` | 4–30 s in a single pass, native audio + lip-sync, 9:16 |
| TTS (fallback / overlay) | fal.ai ElevenLabs / MiniMax | deterministic verbatim text |
| STT (verification) | fal.ai Whisper | R4 check |
| Lip-sync (optional) | fal.ai `sync-lipsync` | for the TTS-overlay mode |
| Typed judge (optional) | TypeSafe Jev (`typesafe-sdk`) | cheap (~$0.00001/call) typed decisions: script pre-flight, failure classification |
| State | SQLite via SQLModel | queries for eval/compare, idempotency, pydantic-compatible models |
| Media | ffmpeg/ffprobe via a thin wrapper | concat, mux, normalize, probe |
| CLI | typer | one command |
| Logs | structlog → JSONL + stdout | machine-readable logs, `logging.captureWarnings` |
| Tests / quality | pytest, ruff, mypy | guardrails for the agents that write the code |

Alternatives, risks and rationale — in `docs/DECISIONS.md`.
**Note:** the final text of Part 1 of the submission note (stack rationale) is written by the human by hand (the task says "no AI").

## 6. Key decisions (approved 2026-10-21)

1. **Audio strategy** (ADR-002): `native` (Seedance generates speech) with STT verification and an automatic fallback to `tts_overlay`. Config default — `native`.
2. **The line is a first-class input** (ADR-005): the input text contains the line in quotes; the LLM only *extracts* it, the code validates that the extracted text is a substring of the input, and downstream uses **the original from the input**.
3. **Resolution**: we work at 480p; `video.resolution` in config (480p/720p), switchable without code changes. Final samples — 720p.
4. **Shot structure**: 1–2 shots; the shot with the line is generated by a single Seedance call (no cut in the middle of a sentence).
5. **State** (ADR-006): domain state in **SQLite** (SQLModel), media on disk; Prefect keeps only execution state.
6. **LLM**: `anthropic/claude-sonnet-5.5` via OpenRouter ($2/$10 per M tokens vs $3/$15 for 4.6).
7. **Jev (TypeSafe AI)** (ADR-007): typed judge for script pre-flight and WER-gate failure classification. Optional provider behind a Protocol.
